# GranBoi 🐂

GranBoi é um sistema web de gerenciamento agropecuário desenvolvido para auxiliar no controle completo de rebanhos bovinos. O projeto oferece funcionalidades voltadas para gestão de gado, vacinação, controle financeiro, relatórios e administração de usuários, proporcionando mais organização, produtividade e eficiência no gerenciamento da fazenda.

O sistema está sendo desenvolvido utilizando HTML, CSS, JavaScript e PHP, com foco em uma interface moderna, responsiva e intuitiva para facilitar o uso no dia a dia do produtor rural.

## Funcionalidades

* Dashboard com indicadores gerais
* Cadastro e gerenciamento de gado
* Controle de vacinação
* Gestão financeira
* Emissão de relatórios
* Perfil de usuário
* Interface responsiva e moderna

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* PHP

## Objetivo

O objetivo do GranBoi é centralizar e facilitar a administração agropecuária, permitindo um controle mais eficiente das informações do rebanho e das operações da fazenda.
